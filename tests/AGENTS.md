# Praca nad testami aplikacji

- Przed zmianą testów lub ich uruchamiania przeczytaj zasady testowania w [../AGENTS.md](../AGENTS.md).
- Przy analizie wydajności i zmianach schedulera stosuj [TEST-PERFORMANCE-METHODOLOGY.md](TEST-PERFORMANCE-METHODOLOGY.md): najpierw hipoteza i profil, następnie zmiana, kontrola zakresu i pomiar wyniku.
- Historyczne raporty opisują konkretną wersję i środowisko. Nie traktuj ich czasów ani optymalnej liczby workerów jako stałych właściwości projektu.
- Zwykłe zadanie nie wymaga całej serii benchmarków. Wykonuj tylko pomiary uzasadnione poleceniem użytkownika lub konkretną hipotezą.
